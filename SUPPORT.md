# Support for this preview distribution

This is a preview distribution. No public support SLA or guaranteed
response time is established. Use the channel through which you received the candidate
to return reviewed non-sensitive feedback to the project maintainers.

Include VERSION, ZIP SHA-256, OS/CPU, Docker/Python versions, command, exit code,
expected/observed behavior and reviewed evidence paths. Do not attach private keys,
complete keystores, authentication tokens or unreviewed customer data.

For suspected vulnerabilities follow [SECURITY.md](SECURITY.md), not a public issue;
the security reporting address is stated there and only there. This document adds no
other address and does not imply an active public support service.
