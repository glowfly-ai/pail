# 지원 동작과 OEM 확장 진입점

이 문서는 앞으로의 기능 약속이 아니라 현재 지원 경계다. 동일 릴리스의 구성요소를 함께 사용한다.
[호환 규칙](COMPATIBILITY.ko.md), [영문 정본](SUPPORTED_BEHAVIOR.md)을 함께 참조한다.

## 필드가 실제로 하는 일

| 입력·조건 | 진입점 | 현재 의미 | OEM 확장과 한계 |
|---|---|---|---|
| 요청자 | mTLS/UDS 인증 및 요청자 등록부 | 직접 호출자의 신원과 skill 권한을 대조. 본문의 이름으로 신원을 대신하지 않음 | 등록된 주체 설정 가능. 검증된 다단계 AI 위임 사슬은 제공하지 않음 |
| 로봇 | robot_id·로봇 등록부 | 호출·토큰을 지정 로봇에 결속 | ID 이름만으로 인증되지 않음 |
| 행동 | ActionSpec·로봇 종류별 skill | 이름·클래스·호출자 허가 확인. v5는 skill·slot 결속 | 지원되는 skill 구성 가능. 이름 등록만으로 드라이버가 생기지 않음 |
| 대상 | target_object_id·모델·관측 입력 | 설정한 형상에서 모델 등록과 필수 대상 증거 확인 | 공개 ABI로 관측 연결. 선언된 객체가 실물 존재의 증명은 아님 |
| 시간 | 서명된 유효 기한·단계 시간 | 게이트가 시간 조건 검사. 재조회는 만료 시각을 연장하지 않음 | 지원 범위 안의 설정 가능. 시험을 위해 호스트 시계를 바꾸지 않음 |
| 명령 속도 | Twist·이름 있는 한도 | 지원 어댑터의 선속도·각속도 명령값과 한도를 검사 | 실제 제동 성능의 측정·인증은 아님 |
| context_json·constraints_json | 계획 API | JSON 형식·크기 확인과 해시·기록. 임의 내용의 의미는 정책으로 판단하지 않음 | approved:true는 검증된 사람 승인이 아님 |
| params_json | skill 파라미터 | JSON 검사. 알려진 수치 guardrail 키는 한도 축소·초과 거부에 사용 | 임의 목적지·목적·승인 키가 자동으로 인가 효력을 갖지 않음 |
| params_schema | skill 등록부 | 미지원. 선언하면 설정 거부 | JSON Schema 엔진은 제공하지 않음 |
| 구역·목적지 | site model·이벤트·작업 파라미터 | 정적 모델 규칙은 있음. 범용 실시간 로봇 구역 이동·목적지·지오펜스 집행은 제공하지 않음 | 구역·목표를 기록했다는 이유로 이동 경계를 보장하지 않음 |
| 힘·관절 | guardrail 어휘 | 이름이 있어도 해당 어댑터의 측정·집행이 있다는 뜻은 아님 | 지원 측정값만 선언. 힘 제어기를 대신하지 않음 |
| 사람 승인 | 계획 제출 전 OEM 시스템, 별도 운영 관리 승인 API | 운영 관리 승인은 개별 물리 행동의 승인이 아님 | 앞단 승인은 우회 불가능한 인증 경로·취소 처리가 필요. 이슈어 직접 검증은 별도 계약 필요 |
| 게이트 판정 | 공개 ABI·ReportDecision | 허용·차단, 완료 보고, 이슈어 완료 수용은 다른 사실 | 서명 원문과 보고 신원 보존 |
| 완료 | complete.signal·보고 | 지원하는 완료 신호에 따라 소비. journal v10은 수용 결과를 명시 | [완료 기록 규칙](COMPLETION_JOURNAL.ko.md). 보고·수용이 물리적 성공의 증명은 아님 |
| 증거 | Blackbox·공개 검증기 | 주어진 신뢰 기점에 대한 지원 범위의 서명·연결·주장 검사 | 입력 부재는 성공이 아님. 무결성 검증이 정책 전체·센서 진실의 증명은 아님 |

## 기체·어댑터 범위

[ADAPTERS.tsv](ADAPTERS.tsv)의 실제 측정값·정지 요청 동작·시험 상태와
[어댑터 계약](ADAPTER_CONTRACT.ko.md)의 우회 방지 책임을 확인한다.
어휘집에 로봇 종류가 있다는 사실을 모든 기체의 검증·인증으로 표시하지 않는다.
모의·실물 결과와 제외 항목, OS·아키텍처를 나누어 표시한다. 로봇 안전 제어는 별개다.

## OEM이 연결하는 방법

1. 지원하는 요청자·skill·정책·세계 모델을 설정한다.
2. 토큰·명령·안전·증거 ABI에 어댑터를 연결하고 허가된 경우에만 원래 명령을 전달한다.
3. OEM의 승인·위임 검사는 앞단에 둘 수 있다. 무단 직접 제출 경로와 취소·변경을 함께 관리한다.
4. 새로운 이슈어 판단이나 서명 권한의 의미는 context_json의 콜백이 아니다.
   명시적인 버전 계약과 구현이 필요하며 소스의 등록 함수는 런타임 플러그인과 다르다.

미지원 필수 조건을 버리고 더 넓은 권한으로 바꾸지 않는다. 선택적 업무 정보는
기록할 수 있지만 실제 집행 조건이 아니라 주장임을 표시한다.
