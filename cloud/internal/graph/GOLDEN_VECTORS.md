# CG0 Golden Vectors

Frozen deterministic-encoding reference for `internal/graph`. Any change to these
values means the canonical encoder (and therefore the evidence hash format) has
changed — that must be an intentional, reviewed decision, never an accident.
`TestGoldenVector` enforces these; `TestCrossCheck` independently re-derives the
same bytes via a second encoder implementation.

This vector is case `SG-01` of the public conformance set
`spec/subgraph-vectors/` (generated by `cmd/gensubgraphvec`, specified by
`spec/SUBGRAPH_HASH.md`, re-derived by `spec/tools/spec_subgraph_check.py`).
The checker pins the hash below to that set (`golden_g1_sha256`), so this file
and the set cannot drift apart silently.

## Vector G1 — `goldenSubgraph()`

## Encoder invariants proven by tests

- **Order independence**: node/edge/attr insertion order does not change the hash
  (`TestDeterminismOrderIndependent`).
- **Cross-implementation**: an independent second encoder yields identical bytes
  (`TestCrossCheck`).
- **Fail-closed rejects**: KindUnspecified, NaN/Inf double, duplicate node_id all
  error instead of producing bytes (`TestRejectPaths`).
- **-0.0 == +0.0**: negative zero normalizes (`TestNegZeroNormalized`).
